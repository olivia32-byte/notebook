# 두암 디지털 공책 · 서버 설정 안내

선생님이 한 번만 하면 되는 준비입니다. 모두 무료 요금제(Spark)로 시작할 수 있어요.

## 1. Firebase 프로젝트 만들기
1. https://console.firebase.google.com 에 학교용 Google 계정으로 들어갑니다.
2. **프로젝트 추가** → 이름(예: `duam-notebook`) → Google 애널리틱스는 꺼도 됩니다.

## 2. 웹 앱 등록하고 설정값 받기
1. 프로젝트 첫 화면에서 **</> (웹)** 아이콘을 누릅니다.
2. 앱 이름(예: `공책`)을 넣고 등록합니다. "Firebase 호스팅"은 체크하지 않아도 됩니다.
3. 화면에 나오는 `const firebaseConfig = { apiKey: ..., authDomain: ..., ... }` 부분을 **통째로 복사해서 Claude에게 보내 주세요.**
   이 값은 웹페이지에 공개되는 값이라 알려 줘도 괜찮습니다. 실제 보호는 4번의 보안 규칙이 합니다.

## 3. 로그인 방법 켜기
1. https://console.firebase.google.com/project/notebook-3dca6/authentication/providers 를 엽니다. (왼쪽 메뉴에서는 **보안 → Authentication**에 있을 수 있어요.) "시작하기"가 보이면 누릅니다.
2. **로그인 방법** 탭에서 아래 두 가지를 "사용 설정"합니다.
   - **Google** (선생님 로그인용)
   - **이메일/비밀번호** (학생 로그인용. 실제 이메일은 받지 않고, 반 코드·번호로 자동으로 만들어요)
3. 같은 Authentication 화면의 **설정 → 승인된 도메인**에 앱 주소를 추가합니다. GitHub Pages라면 `아이디.github.io` 입니다.

## 4. 데이터베이스 만들고 보안 규칙 넣기
1. https://console.firebase.google.com/project/notebook-3dca6/firestore 를 열고 **데이터베이스 만들기**를 누릅니다. (왼쪽 메뉴에서는 **데이터베이스 및 스토리지 → Firestore Database**에 있을 수 있어요.)
2. 위치는 **asia-northeast3 (서울)** 을 고릅니다. (학생 자료가 국내에 저장됩니다.)
3. **프로덕션 모드**로 시작합니다.
4. 만들어지면 **규칙** 탭을 열고, 들어 있는 내용을 모두 지운 뒤 `firestore.rules` 파일 내용을 붙여 넣고 **게시**합니다.
   - 학생은 자기 공책만 읽고 쓸 수 있어요.
   - 선생님은 자기가 만든 반의 공책만 볼 수 있고, 피드백(빨간 펜, 도장)은 선생님만 쓸 수 있어요.

## 5. 웹 주소 만들기 (GitHub Pages)
1. https://claude.ai/connect-github 에서 GitHub 계정을 연결합니다. (계정이 없으면 github.com에서 무료로 만듭니다.)
2. GitHub에서 **New repository** → 이름 `notebook` → Public → 만들기.
3. 저장소 이름을 Claude에게 알려 주면 파일을 올리고 Pages를 켜는 방법을 안내해 드립니다.

## 수업에서 쓰는 순서
1. 선생님: 앱 주소 → **Google 계정으로 로그인** → **새 반 만들기** (6글자 반 코드가 생깁니다).
2. 선생님: **학생 등록**에 번호와 이름(또는 별명)을 넣습니다. 학생마다 6자리 비밀번호가 생깁니다.
3. **학생 비밀번호 카드**를 보고 학생에게 나눠 줍니다.
4. 학생: 갤럭시탭 크롬에서 앱 주소 → 반 코드, 번호, 비밀번호 입력. 한 번 로그인하면 다음부터는 바로 열립니다.
5. 학생 탭에서 크롬 메뉴 → **홈 화면에 추가**를 하면, 주소창 없이 전체 화면 앱처럼 열립니다.
6. 학생이 앱 밖으로 나가지 못하게 하려면 갤럭시탭의 **앱 고정** 기능을 함께 씁니다.

## 개인정보 관련 참고
- 학생에게서 받는 정보는 반 번호와 선생님이 넣은 이름(또는 별명), 필기 내용뿐입니다. 이메일·전화번호는 받지 않습니다.
- 정식으로 수업에 쓰기 전에 학교의 **학습지원 소프트웨어 선정 절차**(학교운영위원회 심의)와 **보호자 동의**가 필요한지 확인해 주세요.
